11. Working directory:This refers to the local files we create on our pc.No command is moved to the working directory as it is the first zone
. Staging area:This s the zone in git where we give instruction and where all work is done.git add is the command to move from working directory to staging area.
.Local repo:This is the zone where we commit and preparation to send to gihub is done.git commit is the command to move from staging area to local repo.
Remote:This is the final phase where our work is being sent to and is seen online also known as github.git push is the command used to move from the local repo to the remote.
To move from remote to local repo we use git pull,to move from local repo to staging area we use git restore
12. The staging area exist and cannot be skipped because all our instructions are being ran in this zone for it to effectively run into the local repo.
